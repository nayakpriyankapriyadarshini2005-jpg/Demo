Diff btwn var let & const

  1. let & const are block scoped where as var is functional or global scope:
  2. let and var can be reassigned, whereas const can not be reassigned:
  3. Redeclaration is possible incase of var keyword whereas redeclaration is not possible incase of let & const keyword:
  4. if we try to access the variables declared with var keyword before their declaration then these variables will be undefined, whereas if we try to access variables declared with let and const before there declaration then it will genetate reference error(because values are present inside TMP-Temporaral Dead Zone):
